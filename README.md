# 《AI量化系统工程：研究、开发与验证》

一本中文技术书稿。以一个**已经跑起来的**事件驱动量化系统为解剖对象，按"研究 → 开发 → 验证"三段展开，讨论在真实约束（单机、真实数据、真实回执、真实故障）下如何把系统做出来，又如何诚实地证明它做到了什么。

写作原则只有一条：**每个结论都要有材料支撑；没有材料，就写明"没有"。** 因此书里大量出现"口径留白""不能由现有材料推出"这类表述——这不是保守，这就是本书的方法论。

## 怎么读

直接打开 `全书合稿/AI量化系统工程_全书合稿_v1.0.html`。目录、锚点、表格、公式都在单文件内，不依赖网络。

## 怎么重建

需要 Python 3.11+ 与 `markdown`（含 `toc` 扩展）：

```bash
pip install markdown
cd 全书合稿
python _build.py
```

脚本会先断言单元数为 26、目录占位符存在、**目录链接不得悬空**，任一失败即中止，不产出半成品。

「生成日期」默认取当天，所以跨天重建只有这一行会变。要逐字节复现：

```bash
BUILD_DATE=2026-10-28 python _build.py
```
